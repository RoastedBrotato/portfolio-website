## Writing a new post

Drop a new `.mdx` file in `content/blog/`, matching this file's frontmatter shape:

```md
---
title: "Post Title"
description: "One sentence for the listing page and search results."
date: "2026-09-10"
tags: ["ai", "backend"]
---

Regular Markdown/MDX body goes here.
```

The listing page, the post page, and the `⌘K` search all pick it up automatically — no other code changes needed.
